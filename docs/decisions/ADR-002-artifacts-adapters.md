# ADR-002：不可变产物与适配器边界

- 状态：accepted
- 日期：2026-08-09
- 决策者：项目维护者
- 替代：无
- 被替代：无

## 背景

内容需要人工编辑、局部重跑、来源追溯和供应商替换。覆盖文件或让业务代码直接调用 SDK 会丢失历史并扩大变更影响。

## 决策

Artifact 采用不可变版本，每次生成、编辑和重跑都创建新记录与新文件；项目仅更新当前版本指针。产物记录上游引用、Source、模板/模型参数和摘要，流水线步骤只通过声明的 Artifact 输入输出交换数据。

文本、语音、图片、素材与渠道能力由适配器实现。领域和流水线依赖自有协议，不依赖供应商 SDK。MVP 每类能力只实现一个默认供应商和一个确定性 Fake。历史产物保留当时的适配器与参数标识，即使适配器被替换也可审计。

## 候选方案

- 就地覆盖文件：存储简单，但无法审计或安全局部重跑。
- 为每个供应商编写独立业务流程：初期直接，但造成流程分叉和迁移成本。

## 影响

获得可追溯、可比较、可恢复的内容历史，并能并行开发适配器。代价是需要血缘、当前指针、垃圾回收和存储配额管理；MVP 先保留全部产物，不提前实现自动清理。
