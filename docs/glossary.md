# 术语表

| 术语 | 定义 |
| --- | --- |
| Source | 可信来源及其抓取时间、摘要和可引用片段。 |
| Topic | 选题、角度、受众、时效性、来源集合和评分。 |
| ContentProject | 一次内容生产项目，记录内容形态、目标渠道、当前版本和状态。 |
| Artifact | 脚本、分镜、配音、字幕、封面、成片等不可变版本产物。 |
| Job | 一次流水线步骤执行，记录输入版本、状态、重试、错误和成本。 |
| Review | 人工修改、审核结论和风险项。 |
| Publication | 渠道参数、幂等键、平台内容标识及发布结果。 |
| 事实卡片 | 从可信来源整理出的结构化事实、引用与不确定性说明。 |
| 产物血缘 | 某个 Artifact 使用的上游 Artifact、来源和生成参数。 |
| 发布包 | 无官方发布权限时导出的成片、封面、文案、标签和操作说明。 |
| ADR | Architecture Decision Record，记录重要且长期有效的技术决策。 |
| 任务文件 | `docs/tasks/` 下的实施规格，是任务内容的仓库内权威来源。 |
| Handoff | 跨人员、Agent 或会话的完成证据与继续执行入口。 |
| Ready | 依赖已满足、接口已冻结且可被直接领取的 backlog 任务。 |
| 失败关闭 | 证据、权限或质检不满足时停止推进，而不是默认放行。 |
