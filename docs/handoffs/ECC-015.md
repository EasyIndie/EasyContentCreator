# ECC-015 交接

## 交付

- 冻结带乐观并发 revision 的 ContentProject、结构化 Source 引用、Artifact/ArtifactRef 和安全相对存储路径。
- 冻结 Provider 的 `generate` 及 Publisher 的 `validate/publish/status/metrics` 协议。
- 定义可重试、永久、适配器契约和非法状态转换错误。
- 接受 ADR-004，并同步架构与路线状态。

## 后续约束

- Repository 必须将枚举保存为字符串、时间保存为 UTC、元数据保存为 JSONB，并以 `revision` 条件更新防止丢失更新。
- Worker 只自动重试 `RetryableError`，其他领域错误失败关闭。
- Worker 不传入失败阶段；领域状态机根据失败前状态推导，防止伪造恢复路径绕过审核。
- 发布重试复用同一幂等键并在重试前查询 Publisher 状态。
- 对公共字段或状态的破坏性变更需先更新或替代 ADR-004。
