## 决策与偏差

- 没有新增 migration；完整复用 001/002、ECC-025 reservation 和 ECC-026 terminal transaction。
- 为修复纵向切片容器实际运行的配置断层，范围最小扩展到 `compose.yaml` 与 `.env.example`；没有让 Settings 接受无前缀别名，也未改变 API Artifact volume。
- handler 以 reservation 为权威装载 Source 和请求字段，不信任可篡改 Job payload。
- Fake 的 `created_at` 在 Worker 启动时固定注入；这是当前确定性 Fake 的已知限制，本任务不改变 Provider 时钟契约。
- FACT_CARD 是首个 Artifact，因此 upstream 为空；Source/excerpt/摘要 citations 构成该切片的完整输入血缘。
- 未集成发布、媒体、Web、真实 Provider 或定时调度。
