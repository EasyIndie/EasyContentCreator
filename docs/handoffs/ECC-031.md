# ECC-031 交接

## 结果

- 新增 `JobView` 安全只读投影；SQL 选择列不包含 payload、lease owner 或 lease expiry。
- 新增 `GET /projects/{project_id}/jobs` 与 `GET /jobs/{job_id}`。
- API 仅返回状态、次数、时间、错误分类和 recoverable；不安全历史错误统一为 `UnknownError`。
- recoverable 仅对 generation-failed 项目的 failed Job 为 true；恢复继续使用新 Idempotency-Key 调用 generate API。

## 验证

- 真实 PostgreSQL 16：`tests/test_job_api.py tests/test_job_executor.py`，15 passed。
- 真实 PostgreSQL 16 完整 Python 回归：116 passed。
- Ruff check 与 strict Mypy 通过。
- API 测试覆盖四种 Job 状态、排序、404/422、OpenAPI 字段白名单与 secret/payload/Source 正文不泄漏。
- recoverable 只标记最新 generation reservation 对应的 failed Job，或具有当前 revision reject 审计的 succeeded Job；历史、非生成与不一致 Job不会被误标。过期租约在清理前显示持久化 running，JobStore 清理后显示 failed/LeaseExpired。

## 风险与后续

- 项目仍是单用户边界；未来多租户必须在 Repository 查询中增加主体授权，不能只依赖响应过滤。
- ECC-032 可直接消费冻结的 JobResponse，不应自行推导 recoverable 或解析错误正文。
