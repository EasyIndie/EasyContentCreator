# ECC-036 交接

## 结果

- `packages/domain/pipeline.py` 提供 PipelineRun/StepRun 状态与不变量、LogicalArtifactRef、StepRunSpec 和 reservation-pinned terminal projection。
- `packages/pipeline/contracts.py` 提供 PipelineDefinition/StepDefinition、静态绑定与环校验、冻结 `short_video_v1`、canonical hash 及纯 handler protocol。
- `ArtifactKind` 增加 M2 kinds；既有 `ArtifactRef` 现在明确拒绝 bool version。

## 冻结边界

- M2 handler 输入必须使用 LogicalArtifactRef；不得用缺 logical key 的 M1 ArtifactRef 作为 StepRun 输入。
- StepRun 只有 `pending/succeeded/failed/invalidated`；queued/running/retry 继续由 Job 表达。
- 每个 ECC-036 StepRun 预留一个输出 Artifact；channel package 是 approval-triggered，其余节点 automatic。
- canonical hash 覆盖 project/run、step kind/version、完整排序输入、parameters、profile 与 output kind/logical key。
- 本任务没有 migration、Repository、Worker、API 或媒体实现。
