# ECC-039 交接

## 结果

- `packages/providers/text.py` 提供版本化、规范 JSON 的 TOPIC_BRIEF/SCRIPT 确定性 Fake。
- `packages/pipeline/text.py` 实现 ECC-036 `StepProducer`：解析精确 binding/reservation，通过只读
  `InputArtifactResolver` 取得 pinned Artifact，并返回单一 `StepProductionResult`。
- TopicBrief 从 FACT_CARD 继承完整 citations；Script 从 TopicBrief 继续继承同一 closure。两步输出
  metadata 固定 input SHA、schema、template 和 provider version，upstream 固定精确输入 ref。

## 边界与失败语义

- Producer 不接收 Job/lease，不调用 `StepTerminalPort`，也不修改 StepRun、项目、数据库或 Worker。
- `TextEvidenceError`：输入无 citation、citation 重复/缺失/额外、resolver 返回非 pinned Artifact，或
  reservation 路径已存在不同字节。
- Provider bytes 必须是无重复字段的 canonical UTF-8 JSON；对象字段白名单、文档 type/schema、input SHA、
  citation keys、文本字段类型，以及 result 的 provider/schema/template version 均与冻结请求精确匹配。
- `TextBudgetExceeded`：Provider consumed units 或规范 UTF-8 JSON bytes 超出 `budget_units`。
- 无日志调用，异常仅包含分类语义，不包含输入或生成正文。
- 最终 JSON 从可信 storage root dirfd 逐级以 `O_DIRECTORY | O_NOFOLLOW` 打开父目录；发布前后重走
  root 并复核 parent device/inode。每次执行使用唯一 `O_EXCL` attempt 文件，完整写入并 fsync/close 后
  以 hard-link no-replace 发布，再 fsync 目录并通过安全 fd 复核 final inode、单硬链、摘要和 bytes。
- 同 bytes 重试复用；异 bytes、symlink/非普通文件或 parent swap 失败关闭。旧的唯一 attempt 残留不参与
  后续发布、不毒化 reservation；它是无数据库引用的可识别 orphan，由 ADR-007 约定的后续保留期 GC 清理。
