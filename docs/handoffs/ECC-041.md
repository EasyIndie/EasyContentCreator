## 已完成

- `packages/media.LocalAssetImporter` 只接受 import/artifact root 下规范 POSIX 相对路径。两个 root 每次
  导入重新以 `O_DIRECTORY | O_NOFOLLOW` 打开；其下来源父目录、目标父目录、attempt、锁和最终文件
  全部从可信 dirfd 逐级访问，不经过 `resolve()` 后的路径复用。
- JPEG/PNG/MP4/WAV/MP3 在 SHA-256 匹配后执行容器/EOF 结构校验，再交给受控绝对路径的
  `ffprobe`/`ffmpeg` 以固定 argv、无 shell、30 秒超时及 `-xerror -err_detect explode` 完成 probe 和完整
  解码；损坏、可部分解码坏帧、伪装与尾随 polyglot 失败关闭，decoder stderr 不进入异常或日志。
- 导入在最终目录以安全 fd 写 attempt 并 fsync；锁内重走父目录并比对 device/inode，以 hard link
  原子 no-replace 发布。`EEXIST` 后只通过 `O_NOFOLLOW` fd 验证 regular、单硬链、摘要、结构与解码；
  解码完成后再次 `fstat` 并重算 SHA/size；目标抢占、parent swap、解码窗口同 inode 改写和发布后额外
  hard link 都失败关闭。
- `AssetSource`、`AssetRights`、`AssetManifestEntry` 与 `AssetManifest` 冻结来源、许可类型、证明 URI、
  commercial/modification/distribution scope、到期时间、Artifact ref、MIME 和字节数。
- `rights_issues(at=...)` 稳定返回 unknown、expired 与 scope missing code，供 ECC-043 映射为 QC blocker；
  public metadata 递归冻结且不包含文件路径。
- 错误消息只返回安全分类描述，不记录源名、目标路径、artifact root 或正文。

## 决策与边界

- 不改 ECC-036 公共冻结类型，仅新增独立素材权利契约并复用 `LogicalArtifactRef`。
- source/proof 只允许无 userinfo/query/fragment 的 HTTPS URL 或无 query/fragment 的 URN；服务器
  `file:` URI、带 token URL 和存储路径不得进入 manifest。
- known license 必须有 proof URI；无到期时间表示长期有效，但仍须具备全部三项 M2 rights scope。
- 文件导入与数据库 StepRun 终态尚未耦合；ECC-038 handler 必须在文件完成后才提交 DB 终态。
