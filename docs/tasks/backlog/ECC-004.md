# ECC-004：应用工程脚手架

## 目标与背景

建立可本地运行和测试的 FastAPI、Worker、React 与 PostgreSQL 最小纵向切片。

## 文件范围

- 允许：`pyproject.toml`、Python/Node 锁文件、`apps/**`、`packages/**`、`tests/**`、`migrations/**`、必要配置样例与本任务/handoff。
- 禁止：`.github/workflows/**`、`deploy/**`、ADR 内容。

## 输入与接口

读取 ADR-001、ADR-002；API 提供 `/health`，Worker 提供一次性健康执行入口，Web 展示 API 健康状态。只使用 Fake provider。

## 实施要求

- Python 包按 `architecture.md` 创建且可导入；FastAPI 使用应用工厂。
- React 使用 TypeScript，开发时通过配置访问 API。
- 建立初始迁移和 PostgreSQL 连接配置；配置从环境变量读取并提供无密钥样例。
- 提供后端、前端和纵向健康测试，不实现 M1 领域逻辑。

## 验收标准

- 后端测试、类型检查、前端测试与生产构建通过。
- API、Worker、Web 可分别启动，健康切片可使用本地 PostgreSQL 验证。

## 验收命令

```bash
python -m pytest
python -m mypy apps packages
npm --prefix apps/web test -- --run
npm --prefix apps/web run build
```

## 风险与回滚

依赖版本必须锁定；无法在支持的 Python/Node 版本安装即阻塞。回滚该任务提交即可。
