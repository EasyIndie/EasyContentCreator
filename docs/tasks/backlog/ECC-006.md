# ECC-006：Worktree 与任务交接工具

## 目标与背景

用小型脚本减少领取任务、创建 Worktree、校验状态和生成 handoff 的机械成本。

## 文件范围

- 允许：`scripts/task-*`、对应测试、`docs/runbooks/agent-workflow.md`、本任务/handoff。
- 禁止：应用代码、CI、部署和 ADR。

## 输入与接口

读取 `AGENTS.md` 和任务模板。命令接口固定为 `task-start ECC-NNN [worktree-parent]`、`task-check ECC-NNN`、`task-handoff ECC-NNN`。

## 实施要求

- `task-start` 校验任务存在、状态 Ready、依赖 completed、分支/Worktree 不冲突后创建 `task/<id>-<slug>`。
- `task-check` 校验元数据、文件范围提示、Git 状态和验收命令是否声明，不执行破坏性操作。
- `task-handoff` 从模板创建未存在的 handoff，禁止覆盖。
- 错误返回非零并给出可操作信息；脚本兼容 macOS 与 Linux 常用 shell。

## 验收标准

- 在临时 Git 仓库覆盖成功、依赖未完成、重复 Worktree 和重复 handoff 场景。
- Runbook 可让新 Agent 独立完成领取到交接流程。

## 验收命令

```bash
bash tests/scripts/test-task-tools.sh
git diff --check
```

## 风险与回滚

脚本不得删除分支或 Worktree；失败应保持原状态。回滚脚本与文档提交。
