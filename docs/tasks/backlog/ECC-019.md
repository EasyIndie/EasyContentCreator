# ECC-019：PostgreSQL 租约 Job 执行器

## 目标与背景

实现 ADR-001 的原子认领、续租、有限重试和进程恢复，并接入现有 PollingWorker 生命周期。

## 文件范围

- 允许：`packages/pipeline/jobs.py`、`packages/pipeline/__init__.py`、`apps/worker/**`、必要的追加迁移、`tests/test_job_executor.py`、`tests/test_worker.py`、本任务与 handoff。
- 禁止：领域公共模型、API、Web、适配器实现、部署与 ADR。

## 输入与冻结接口

- 使用 ECC-017 jobs schema；状态固定 `queued/running/succeeded/failed`。
- `enqueue(kind, project_id, payload, max_attempts, available_at) -> UUID`；`claim(worker_id, now, lease_for) -> Job | None` 必须用 `FOR UPDATE SKIP LOCKED` 原子领取一条到期 queued 或租约过期 running Job。
- `heartbeat(job_id, worker_id, now, lease_for)`、`succeed(job_id, worker_id, now)`、`fail(job_id, worker_id, error, now, retry_at)` 均校验当前 lease owner；失租 Worker 不能提交结果。
- 仅 `RetryableError` 且 attempt 小于 max_attempts 时重新 queued；其他异常或耗尽次数永久 failed。调用者不得指定 ContentProject failed_stage。

## 实施要求

- PollingWorker 每次只认领一项并调用按 kind 注册的 handler；未知 kind 永久失败。
- handler 执行期间续租可测试，停止信号不认领新 Job；进程退出不主动伪造成功/失败，交由租约过期恢复。
- 日志只含 job/project ID、kind、attempt 和错误分类，不记录 payload 或密钥。

## 验收标准

- 并发认领同一 Job 仅一个 Worker 成功；租约到期可由另一 Worker 恢复。
- 失租提交被拒绝；RetryableError 退避后重试，Permanent/Contract/State 错误失败关闭。
- Worker 停止与现有健康轮询测试保持通过。
