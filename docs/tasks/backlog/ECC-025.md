# ECC-025：生成请求身份与 Artifact 版本契约

## 目标与背景

落实 ADR-005，冻结 FACT_CARD 请求幂等、逻辑 Artifact ID、单调版本预留和 Source citations 规则，为 API 与 handler 提供唯一生成契约。

## 文件范围

- 允许：`migrations/002_*.sql`、`packages/pipeline/generation.py`、`packages/pipeline/__init__.py`、`packages/providers/contracts.py`、`packages/providers/fake.py`、对应 provider/pipeline/数据库测试、本任务与 handoff。
- 禁止：`001_initial.sql`、冻结领域模型、API、Worker、Publisher、Web、部署/Actions 与已接受 ADR。

## 输入与接口

- 新增不可变 `FactCardGenerationSpec(project_id, source_ids, template_version, budget_units)`；source IDs 非空且不得重复，内部规范化为 UUID 字符串升序。
- `canonical_request_hash(spec) -> str` 必须对且仅对 `project_id`、排序后的 `source_ids`、`template_version`、`budget_units` 生成规范 JSON SHA-256。
- 逻辑 FACT_CARD ID 固定为 `uuid5(project_id, "artifact:fact_card")`。
- `GenerationRequest` 必填新增 `output_artifact_id: UUID` 与 `output_version: int`；Fake 返回的 ArtifactRef 必须原样采用它们。
- 追加 `002` migration 建立 generation request/reservation 表，对项目内 Idempotency-Key、Job 和 Artifact ID/version 分别唯一。
- 提供事务型 `GenerationRequestRepository.reserve_and_enqueue(spec, idempotency_key, now, max_attempts) -> GenerationReservation`；同 key/同 hash 返回原 reservation，同 key/不同 hash 抛固定冲突错误。
- 提供纯函数 `citations_for_sources(sources) -> tuple[SourceCitation, ...]`，覆盖每个 Source 的全部 excerpts并按 source/excerpt UUID 稳定排序；缺 Source 由调用者失败，空 excerpts 抛永久证据错误。

## 实施要求

- reservation 事务使用 `SELECT ... FOR UPDATE` 锁定项目；只允许 `draft` 或 generation-failed，原子完成状态转换、单调版本预留、generation request 和固定 kind `generate_fact_card` Job 插入。
- 重复幂等请求必须先于当前状态拒绝判断返回原 reservation，使项目已进入 generating 后客户端仍可安全重试。
- version 同时考虑已持久化 Artifact 和尚未完成的 reservation；并发不同 key 请求不能获得相同版本。
- Fake 规范字节包含 output ID/version，retry 与租约恢复对同一 reservation 必须产生相同字节、路径和摘要。
- 不保留旧的 Fake 自派生 Artifact ID/version 路径；相关调用和测试一次性迁移到新必填字段。
- migration 只能追加，不编辑 `001_initial.sql`；迁移重复执行无副作用。

## 验收标准

- source_ids 空、重复、非法预算/模板失败关闭；不同输入产生不同 canonical hash，输入顺序不影响 hash。
- 同 key/同请求在串行和双连接并发场景都只生成一个 Job/reservation；同 key/不同请求冲突且不改变项目。
- 同项目 FACT_CARD 的连续请求保留同一逻辑 ID并单调获得 version 1、2；失败/未完成 reservation 也不复用版本。
- Fake 跨实例对同一预留请求字节完全一致，并严格保留预留 ID/version。
- citations 完整覆盖全部 excerpts，排序稳定，空 excerpts 永久失败。
