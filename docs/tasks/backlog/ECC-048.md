# ECC-048：ReviewBundle 与受权媒体 API

## 目标与范围

实现 immutable ReviewBundle、pipeline/review projection、项目 ownership 媒体 Range 路由及 approval/reject pinning。只改 domain/pipeline/api/migrations/tests/docs；不改 Web/发布包。

## 验收

- bundle hash 钉住 revision/profile/全部 refs/QC/evidence/license；后端 fail-closed 计算 can_approve。
- approval/reject 要求 bundle hash+expected revision；stale/invalidated/QC blocker 不可批准，reject 只调度合法子图。
- 内容路由 SQL 校验 ownership，MIME 白名单、ETag/Range 正确，不返回路径/payload/正文；404/409/416/422 完整测试。
- 真实 PG+文件 round-trip、并发/回滚、安全日志和全量门禁通过。
