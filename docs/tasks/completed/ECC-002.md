# ECC-002：产品愿景与路线

## 目标与背景

把内容路线、质量原则、术语、里程碑和迭代机制固化为后续 Agent 的产品上下文。

## 文件范围

- 允许：`docs/vision.md`、`docs/glossary.md`、`docs/roadmap.md`、本任务和 handoff。
- 禁止：架构正文、应用代码、CI 和部署文件。

## 输入与接口
