# ECC-005：CI 与质量门禁

## 目标与范围

提供快速 PR、完整 CI、安全、文档和夜间检查，以及本地统一验证入口。允许 `.github/workflows/`、`scripts/` 和本任务文档；不修改应用实现与架构文档。

## 验收标准

- 八个工作流语法可解析并设置并发控制。
- PR 覆盖 Python、Web、Compose、文档和密钥检查，完整 CI 构建三类镜像。
- `scripts/verify.sh` 与 CI 使用相同检查入口。

## 执行记录

- 结果：已交付 CI/CD 工作流、本地验证和文档校验。
- 测试：Shell 语法、YAML 解析、文档检查、Compose 配置和 `git diff --check`。
- 偏差：应用脚手架未合并，本分支只做静态验证；依赖安装按约定路径声明。
- 后续：脚手架合并后首次 CI 验证真实依赖与命令名称。
