# ECC-007：单机部署与回滚框架

## 目标与范围

提供 Docker 构建、Compose 单机运行、备份、部署、健康检查、回滚及 GitHub Environments CD 框架，不连接真实环境。

## 验收标准

- 部署和回滚只接受不可变镜像 digest，并使用排他锁。
- 部署前执行备份，部署后执行健康检查。
- staging 自动、production 手动审批，凭据均来自显式 Secrets。

## 执行记录

- 结果：已交付三个 Dockerfile、Compose、部署脚本与运行手册。
- 测试：Shell 语法、Compose 配置及 workflow 静态解析。
- 偏差：未实际推送镜像、SSH 或部署，符合执行边界。
- 后续：应用脚手架合并后构建镜像并在隔离 staging 演练备份与回滚。
