# ECC-010：Web 健康页展示构建版本

## 目标与范围

基于冻结接口 `GET /version -> {version: string, commit: string}`，在 React 健康页展示构建版本和提交。仅修改 `apps/web` 与本任务文档，不修改 API、CI、Compose 或架构。

## 验收标准

- 健康页独立请求 `/health/live` 与 `/version`。
- 版本请求成功时展示 `version` 和 `commit`。
- 版本响应缺失字段或请求失败时明确展示 `unavailable`，且不影响健康请求结果。
- Web lint、test、build 与 `git diff --check` 通过。

- 结果：已完成独立版本请求、成功展示和失败关闭降级。

- 偏差：无。
- 后续：由父任务 ECC-008 按既定顺序集成，并在 staging 验证 Web 与 API 版本一致。
