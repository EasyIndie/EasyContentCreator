# ECC-011：修复首次远程质量门禁

## 目标与背景

首次推送触发的 CI 因 Compose 缺少 `POSTGRES_PASSWORD` 失败；Security 因组织仓库使用 Gitleaks Action 需要商业 License 而失败。

## 实施结果

- CI 同时注入 `ECC_DATABASE_URL` 和仅用于测试的 `POSTGRES_PASSWORD`。
- 使用固定版本的开源 Gitleaks 容器扫描完整 Git 历史，不依赖商业 Action License。
- 将官方 GitHub 与 Docker Actions 更新至已发布的 Node 24 版本，消除 Node 20 弃用告警。

## 验收

- 工作流 YAML 可解析。
- 本地统一验证通过。
- 远程 CI 与 Security 必须在本提交推送后通过；最终运行链接记录在 handoff。

## 执行记录

- 结果：实现完成；远程 CI、Security 与 Docs Check 均通过。
- 测试：Python 6 项、Web 4 项及生产构建通过。
- 偏差：首次远程运行提供了本地无法暴露的组织 License 与环境变量证据。
- 后续：CI 运行 `31296072540`、Security 运行 `31296072555` 可作为首轮修复证据。
