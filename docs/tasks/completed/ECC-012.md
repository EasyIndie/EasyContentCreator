# ECC-012：规范化 GHCR 镜像路径

## 目标与结果

staging 首次执行证明 `${{ github.repository }}` 保留组织和仓库名大小写，生成的 Docker 标签无效。部署与发布工作流现在统一生成小写 GHCR 前缀，并复用于标签和镜像摘要引用。

## 验收

- 工作流 YAML 解析通过。
- staging 能完成镜像构建和推送；服务器连接结果另行记录。

## 执行记录

- 结果：实现完成，等待远程 staging 复验。
- 测试：静态工作流检查和本地文档门禁通过。
- 偏差：无。
- 后续：不得直接使用未规范化的 `github.repository` 构造 OCI 引用。
