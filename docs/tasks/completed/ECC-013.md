# ECC-013：为 staging 增加显式启用门禁

## 目标与结果

当服务器和 Secrets 尚未配置时，持续触发 SSH 部署只会产生无意义红灯。staging job 现在要求仓库变量 `STAGING_ENABLED=true`，部署运行手册明确列出启用前置条件。

## 验收

- CI 成功且变量未设置时 staging job 为 skipped。
- 设置变量并具备完整 Environment Secrets 后才允许进入镜像发布和 SSH 部署。

## 执行记录

- 结果：完成。
- 测试：工作流 YAML、文档门禁通过；GitHub `staging` 与带人工审批的 `production` Environment 已创建。
- 偏差：无。
- 后续：服务器准备完成后设置变量并触发 CI 验证。
