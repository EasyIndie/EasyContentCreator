# ECC-014：增加 AMD64 与 ARM64 多架构镜像

## 目标与结果

CI、staging 和 release 统一构建 `linux/amd64,linux/arm64` 镜像，并使用 QEMU 与 Buildx。新增本地双架构验证脚本，覆盖三类镜像的架构检查以及 API、Worker、Web 启动验证。

## 验收

- 工作流 YAML 可解析，三条镜像链路均声明双架构平台。
- 本机分别构建并加载六个架构/目标组合。
- 两个架构的 API、Worker 与 Web Smoke Test 通过。
- 统一项目验证和 ShellCheck 通过。

## 执行记录

- 结果：实现完成；CI、staging、release 均声明 AMD64/ARM64，release 同时发布 App 与 Web manifest。
- 测试：本机 ARM64 与 AMD64 的 API、Worker、Web 六个构建及容器 Smoke Test 全部通过；统一项目验证与 ShellCheck 通过。
- 偏差：无。
- 后续：远程 PR 验证多平台 BuildKit 构建和必需检查。
