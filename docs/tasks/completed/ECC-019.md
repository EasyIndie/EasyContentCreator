# ECC-019：PostgreSQL 租约 Job 执行器

## 目标与背景

实现 ADR-001 的原子认领、续租、有限重试和进程恢复，并接入现有 PollingWorker 生命周期。

## 文件范围

- 允许：`packages/pipeline/jobs.py`、`packages/pipeline/__init__.py`、`apps/worker/**`、必要的追加迁移、`tests/test_job_executor.py`、`tests/test_worker.py`、本任务与 handoff。
- 禁止：领域公共模型、API、Web、适配器实现、部署、ADR 与 `001_initial.sql`。

## 输入与冻结接口

- 状态固定为 `queued/running/succeeded/failed`。
- `enqueue`、`claim`、`heartbeat`、`succeed`、`fail` 使用 ECC-017 的 jobs schema。
- 认领使用 `FOR UPDATE SKIP LOCKED`；完成操作校验 worker ID 与未过期租约。
- 仅 `RetryableError` 且 attempt 未耗尽时重新 queued。

## 实施要求

- PollingWorker 每次最多领取一项并按 kind 分派，未知 kind 永久失败。
- 同步 handler 执行期间由独立心跳线程续租；停止后不再领取任务。
- 日志与 `last_error` 只记录标识和错误分类，不记录 payload、异常正文或密钥。

## 验收标准

- 两个真实 PostgreSQL 连接并发认领只有一个成功。
- 租约到期可恢复，原 worker 的心跳、成功与失败提交均被拒绝。
- 可重试错误按 available_at 重试并受 max_attempts 限制；其他错误失败关闭。
- Worker 心跳、停止和未知 kind 行为有测试。
