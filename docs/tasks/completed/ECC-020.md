# ECC-020：项目与人工审核 API

## 目标与背景

交付 Web 控制台所需的最小项目查询、创建、状态与人工审核 HTTP 切片，不承载生成或发布编排。

## 文件范围

- 允许：`apps/api/**`、`packages/domain/reviews.py`、对 `packages/domain/repositories.py` 的 ReviewRepository 最小追加、`tests/test_project_api.py`、本任务与 handoff。
- 禁止：迁移、既有 Project/Source/Artifact Repository 行为、Worker、Web、适配器、部署与 ADR。

## 输入与冻结接口

- `POST /projects` 接收 `{title}`，返回 201 的项目详情；`GET /projects` 返回按 created_at/id 降序的 `{items}`；`GET /projects/{id}` 返回项目及 current_artifacts。
- `POST /projects/{id}/reviews` 接收 `{decision:"approve"|"reject", note:string, expected_revision:int}`。approve 仅允许 `review_required -> approved`；reject 仅允许 `review_required -> generating`，均通过 Repository 乐观并发更新并写 Review。
- 项目响应固定含 `id,title,status,revision,failed_stage,created_at,updated_at,current_artifacts`；错误格式固定 `{detail:{code,message}}`，404=`not_found`、409=`revision_conflict|invalid_transition`、422 保留 FastAPI 校验语义。
- Review 为不可变 `{id,project_id,decision,note,project_revision,created_at}`；`ReviewRepository.add(review)` 仅插入，重复 ID 失败，审核记录与项目状态更新使用同一数据库事务。

## 实施要求

- Repository 通过 FastAPI dependency 注入，测试可替换；API 不执行原始 SQL。
- note 去除首尾空白后必须非空且最多 2000 字符；审核时间使用注入 UTC clock。
- 不增加删除、发布、重跑、认证或分页游标能力。

## 验收标准

- 创建、列表、详情、批准、驳回均有成功测试。
- 未找到、陈旧 revision、非法状态、空 note 均返回冻结错误且不写 Review。
- 现有 health/version API 保持兼容。
