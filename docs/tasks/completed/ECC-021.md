# ECC-021：项目与审核 Web 控制台

## 目标与背景

把 ECC-020 冻结 API 暴露为可用的项目列表、详情和人工审核纵向页面，同时保留现有健康与版本信息。

## 文件范围

- 允许：`apps/web/**`、本任务与 handoff。
- 禁止：Python、数据库、迁移、CI/Compose、部署与 ADR。

## 输入与冻结接口

- 仅调用 ECC-020 的 `GET/POST /projects`、`GET /projects/{id}`、`POST /projects/{id}/reviews` 与已有 health/version。
- 页面状态固定为：列表 loading/empty/error/content；详情展示 status、revision、failed_stage 和 current_artifacts；审核表单只在 `review_required` 展示 approve/reject、必填 note。
- 409 时显示“项目已更新，请刷新后重试”并重新拉取详情；审核提交中禁用重复提交。

## 实施要求

- 抽出轻量 typed API client；非 2xx 解析冻结错误格式，网络/未知格式统一为 unavailable。
- 不引入路由库或全局状态库；M1 使用单页组件状态完成。
- 可访问性包含关联 label、键盘按钮、status/alert 语义与提交焦点反馈。

## 验收标准

- 用户可创建项目、选择列表项、查看详情并批准或驳回待审核项目。
- 空列表、API 失败、409 冲突和重复点击均有 Vitest；健康或版本失败不遮蔽已有项目内容。
- lint、测试和生产构建通过。

## 验收命令

```bash
npm --prefix apps/web run lint
npm --prefix apps/web test
npm --prefix apps/web run build
./scripts/check-docs.sh
git diff --check
```

## 工作量、风险与回滚

边界为一至两天。风险是单组件膨胀；允许在 `src/` 内按 API/组件拆分但不引入新框架。回滚 Web 变更不影响 API 或数据。

- 测试：ESLint、9 项 Vitest、TypeScript/Vite 生产构建、文档检查与 diff 检查通过。
- 偏差：无。
