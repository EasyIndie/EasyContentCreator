# ECC-029：Source 与 Artifact 证据审阅 API

## 目标与背景

为人工审核提供冻结的只读证据响应，使 reviewer 能核对 Source、excerpt、摘要快照和 Artifact 血缘，而不暴露服务器文件路径。

## 文件范围

- 允许：只读 Repository 方法、`apps/api/**`、API/Repository 测试、本任务与 handoff。
- 禁止：状态机、生成/审核写事务、Web、任意文件读取/下载、迁移（除非只读索引有实测必要）。

## 输入与接口

- `GET /sources/{source_id}`：id、kind、title、uri、retrieved_at、sha256、summary、按 position 的 excerpts。
- `GET /projects/{project_id}/artifacts`：Artifact 版本摘要列表。
- `GET /artifacts/{artifact_id}/versions/{version}`：id/version/kind/sha256/project_id/created_at/created_by/adapter、冻结 metadata、upstream refs、citations；禁止返回 `storage_path` 或文件系统绝对/相对路径。

## 实施要求

- 404 使用现有冻结错误 envelope；project ownership 不匹配失败关闭。
- 响应排序稳定，metadata 只返回持久化 JSON，不读取文件。
- 测试证明 Source/excerpt/SHA 与 citation snapshot 可核对，且序列化结果不存在 storage_path。

## 验收标准

- API 与真实 PostgreSQL round-trip 完整；非法 UUID 422、缺失实体 404、跨项目访问拒绝。
- OpenAPI 响应模型固定且不包含任意文件路径。

## 风险与回滚

主要风险是泄漏存储布局或扩大读取范围；任何文件下载能力必须独立任务设计受控根和 MIME 白名单。

## 执行记录

- 结果：完成 Source 详情、项目 Artifact 版本摘要列表与 Artifact 证据详情三个只读 API；
  Artifact 详情以必填 `project_id` query 参数校验 ownership；公开 metadata 冻结为
  `capability`、`template_version` 与 `parameters.source_ids` 白名单，未知字段失败关闭，响应固定
  排除 `storage_path` 和任意持久化路径字段。404 envelope 已加入 OpenAPI 响应模型。
- 测试：真实 PostgreSQL 16 下 8 项目标测试通过，覆盖 Source/excerpt/citation/upstream/metadata
  round-trip、稳定排序、404/422、跨项目拒绝和 OpenAPI 无路径字段；全量验证结果见 handoff。
- 偏差：任务路径未包含调用方项目上下文，为满足跨项目访问失败关闭，将 `project_id` 设计为
  Artifact 详情接口的必填 query 参数；未新增迁移或文件读取。
- 后续：ECC-030 可基于冻结响应模型实现证据审核 UI。
