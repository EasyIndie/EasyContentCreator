# ECC-034：M1 准出复核

## 目标与背景

在全部收口任务完成后，独立复核 Fake FACT_CARD 链路的恢复、审核、证据、错误安全、Web 和 Compose 运行证据，决定 M1 是否准出。

## 文件范围

- 允许：准出测试/报告、`docs/roadmap.md`、runbook、本任务与 handoff；仅修复复核中发现的低风险文档错误。
- 禁止：顺带实现 M2、真实 Provider、媒体、发布；实现缺陷必须拆新任务。

## 输入与接口

- ECC-028～033 的 completed task、handoff、CI 和 Compose evidence。
- M1 门槛：可恢复、可审核、可追溯、错误安全、Web 可操作、fresh Compose 可启动且迁移失败关闭。

## 实施要求

- 从 fresh PostgreSQL/Artifact volumes 跑 API→Worker→证据审阅→reject→新版本恢复→approve。
- 注入 retryable、永久证据失败、租约恢复、迁移失败；检查无重复 Artifact/Job、无 secret/payload 泄漏。
- Web 以生产构建运行并完成证据审阅、Job 诊断和恢复操作。
- 记录实际 SHA、命令、耗时、失败与遗留风险；任一必需门槛失败则任务 blocked，不得宣布 M1 完成。

## 验收标准

- 全量 CI/verify、独立 Compose Smoke 和 M1 场景矩阵全部通过。
- roadmap 仅在证据齐全时将 M1 标为完成并开放 ECC-035。

## 验收命令

```bash
POSTGRES_PASSWORD=validation-only ./scripts/verify.sh
./scripts/check-docs.sh
git diff --check
```

## 风险与回滚

该任务是门禁而非功能开发；不能用重跑忽略不稳定测试，也不能把本地单测等同真实 Compose 证据。

## 执行记录

- 结果：M1 准出通过；Fake FACT_CARD 在真实 PostgreSQL 与 fresh Compose 中满足可恢复、可审核、可追溯、错误安全及迁移失败关闭门槛。
- 测试：`main@0013fc2` 上最终统一验证 129 项 Python、Compose 3 项、Web 22 项与生产构建通过，其中新增独立 Compose M1 Smoke 1 项。详见 `docs/iterations/M1-exit-audit.md`。
- 偏差：首次新增 Smoke 使用 Docker Desktop 发布端口的 `127.0.0.1` 访问 Web 得到 400；确认 API 全链路已通过后，将宿主访问改为 `localhost` 并独立重跑通过。未修改产品实现。
- 后续：创建 ECC-035 任务规格，冻结 M2 通用步骤与媒体/质检/发布包契约后再开始实现。
