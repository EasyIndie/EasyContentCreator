# ECC-036：PipelineRun 与 StepRun 冻结领域接口

## 目标与范围

实现 ADR-007 的 PipelineDefinition/Run、StepDefinition/Run、ArtifactRef/logical key、规范 fingerprint、状态与 handler protocol。只改 `packages/domain`、`packages/pipeline`、对应单测和文档；不改数据库/API/Web/媒体实现。

## 验收

- `short_video_v1` 拓扑、slot、版本可静态校验：缺节点、环、kind/slot 不匹配失败。
- canonical hash 对排序输入稳定，任一冻结字段变化均改变摘要；bool 不冒充 int。
- StepRun 不复制 Job queued/running 真相，类型禁止未钉版本/SHA 的输入。
- Ruff、strict Mypy、相关 pytest、docs check、diff check 通过。

## 风险

这是公共接口；任何语义歧义先补 ADR，不为 M1 创建兼容旁路。

## 执行记录

- 结果：新增不可变 PipelineRun、StepRun、LogicalArtifactRef、版本化 DAG 定义、handler protocol 与 canonical request hash；`short_video_v1` 的节点、绑定、kind、logical key、profile 和 approval trigger 均可静态验证。
- 测试：目标领域测试 22 项通过；全量快速测试 86 项通过、74 项因缺少数据库条件跳过、3 项 Compose 标记排除；Ruff format/lint 与 strict Mypy 全部通过。
- 偏差：为保持既有 M1 `ArtifactRef` 调用稳定，M2 通过强类型 `LogicalArtifactRef` 强制 logical key，StepRun 接口只接受该类型；未形成兼容旁路。
- 后续：ECC-037 根据冻结接口追加 migration/Repository；ECC-038 再实现通用终态和 reconciler。
