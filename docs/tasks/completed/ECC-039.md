# ECC-039：选题与脚本确定性步骤

## 目标与范围

实现 TOPIC_BRIEF、SCRIPT 的版本化 schema、确定性 Fake provider、handler 与契约测试。只改
domain/pipeline/providers 对应模块、fixtures/tests/docs；不改持久化、调度、媒体。

## 验收

- 输出钉住完整 FACT_CARD citations、模板/provider 版本和输入 SHA；重复输入产生可复现字节。
- 空证据、额外/缺失 citation、预算越界失败关闭；日志不含正文。
- handler 符合 ECC-036，不自行提交 Job 终态；Ruff/Mypy/pytest/docs/diff 通过。

## 执行记录

- 结果：新增 TOPIC_BRIEF/SCRIPT 确定性文本 Provider 与 `TextStepProducer`。Producer 只通过注入的
  resolver 读取请求钉住的单一 Artifact，不读取 current pointer；输出原样继承全部 citation，记录
  input SHA、schema、template 与 provider version，并返回冻结的 `StepProductionResult`。
- 失败关闭：空/重复/额外/缺失 citation、解析结果与 pinned ref 不一致、非法或超限预算、同 reservation
  路径异字节均抛出安全永久错误；实现不记录正文。
- 测试：目标文本与冻结 Pipeline/Fake 合集 31 项通过；全量非 Compose 87 passed、Compose 3 passed、
  Web 22 passed 且 production build 通过，完整环境证据与偏差见 ECC-039 handoff。
- 偏差：冻结 `short_video_v1` 以 FACT_CARD 为 external input，因此本任务实现的可执行边界是
  `FACT_CARD → TOPIC_BRIEF → SCRIPT`；FACT_CARD 已保存的 SourceCitation 构成来源证据入口，未新增
  与 ADR-007 冲突的 `SOURCE → TOPIC` 旁路。

## 风险

当前是确定性 JSON Fake 与纯 Producer；终态事务、Repository 与 Worker 注册分别属于 ECC-037/038
及后续集成任务。本任务不宣称数据库或纵向链路完成。
