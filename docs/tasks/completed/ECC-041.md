# ECC-041：素材授权与安全导入边界

## 目标与范围

实现本地素材导入、license/rights manifest、摘要与 artifact-root 安全边界。只改 media/providers/domain/tests/runbook/docs；不做网页抓取、浏览器自动化或渠道发布。

## 验收

- 拒绝绝对/穿越/NUL/symlink escape、MIME 伪装和摘要漂移；导入为不可变相对路径。
- 每个外部素材有来源、许可类型/范围/到期状态；unknown/expired 阻塞 QC。
- 临时写、原子 rename、同摘要恢复/异摘要冲突与日志脱敏测试通过。

## 执行记录

- 结果：新增受控 import root 到 artifact root 的 `LocalAssetImporter`，拒绝非规范路径、符号链接、
  MIME 伪装和摘要漂移；同文件系统临时写入、fsync、协作锁和原子 rename 保证不可变目标，同摘要
  恢复复用、异摘要失败关闭。新增 `asset_rights_v1` manifest 契约，冻结 HTTPS/URN 来源、许可证明、
  rights scope、到期时间和安全公开 metadata。
- 测试：16 项目标测试覆盖路径/NUL/symlink、MIME、摘要、原子 rename、恢复/冲突、错误脱敏、
  unknown/expired/scope 不完整 QC blocker、完整 rights 与不安全 provenance URI；Ruff、strict Mypy、
  全量非 Compose Python、docs 和 diff 检查通过。
- 偏差：未修改 ECC-036 冻结的 PipelineRun/StepRun/LogicalArtifactRef；未实现 Web、FFmpeg、网页抓取、
  数据库或发布能力。
- 后续：ECC-043 QC 将 `AssetManifest.rights_issues()` 的稳定 issue code 投影为 blocker。
